# 0002: Borrow the guide pattern, apply the Soft brand

Date: 2026-11-10. Status: accepted.

Adapt the layout and component approach of yck2024/ai-prompt-assistant: shared wrapping navigation, two-column introduction, steps, cards, notes, screenshot frames, narrow reading pages, release articles and native FAQ disclosures. Avoid copying its notebook palette or unrelated illustrations. The extension's approved Soft brand provides violet surfaces, 12px corners, island shadows, Assistant typography, sketched pen-and-cloud marks and the existing cloud-plane doodle.

Keep light and dark token values in the supplied tokens.css and follow system appearance on this independent website, as the extension popup does. Hand-drawn character stays in approved artwork and a small heading underline; no gradients, emoji, glass effects or extra illustration generation.

Self-host fonts with their OFL license. Convert all five real store screenshots to WebP; preserve complete screenshots, link them at full size, and provide descriptive alt text and captions.
